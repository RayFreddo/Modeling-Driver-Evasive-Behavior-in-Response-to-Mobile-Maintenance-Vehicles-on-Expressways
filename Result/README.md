# Results used in the current manuscript

These files summarize the five date-held-out folds, 4,890 trajectories, current HGB-ECR model and five comparators. The obsolete gate-model row was removed from `overall_prediction_errors.csv` to match manuscript Table 7b. The earlier 470-sample eight-model result was archived outside this upload-facing directory. These summary files do not contain raw trajectories or trained weights. The manuscript reports rounded values.
